Magic Kettle 1.0.8: a running Steam or Epic no longer shows as closed on its card.

## New in this version

- **A store's card shows that its client is running, however it was started.** Every few seconds Magic Kettle
  looks at which store clients run, and once in a while it asks Wine whether a client has a window open. When that
  question happened to be the first thing to run in the store's bottle, at the same moment the client started, it
  also started Wine's own background service, which stays for as long as the client runs and kept the question's
  answer open. Magic Kettle waited for the answer to end, and these checks stopped for good: Steam went on running,
  and even started its game, but its card kept saying it wasn't running, and closing its window no longer made
  Magic Kettle quit it. Magic Kettle now takes the answer as soon as the question is done. If a card is stuck
  like this right now, quit Magic Kettle and open it again; the store's client can stay open.

## What to watch for

- Start a Steam game while Steam is closed: once Steam is up, its card should show it running, and closing Steam's
  window should still quit it after the game.
