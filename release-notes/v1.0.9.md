Magic Kettle 1.0.9: mod managers like r2modman can run with Steam, and the mods they install load.

## New in this version

- **Mod loaders next to a game's exe now load.** BepInEx (which r2modman and Thunderstore install) puts a small
  `winhttp.dll` next to the game, MelonLoader a `version.dll`, ASI loaders a `dinput8.dll`, and Windows loads the
  game's own copy first. Wine preferred its own built-in one, so the game started without any of its mods, with
  no error. Magic Kettle now lets the copy in the game's folder win for these three, as on Windows; a game without
  one still gets Wine's. This applies to every game, including Steam games started from a mod manager.
- **Mod managers work with Steam games by themselves: open r2modman's exe and use it as on Windows.** Tested
  start to finish with r2modman and Muck: opened from Downloads, r2modman installed BepInEx and Map Fix, and "Start
  modded" started Muck through Steam with both loaded. Four things made that work:
  - Magic Kettle knows mod managers (r2modman, Thunderstore Mod Manager, Gale, HedgeModManager, Vortex, the Nexus
    Mods app) by their exe and runs them beside the store's games from the first launch, in Steam's Windows (or
    Epic's when there is no Steam). In Windows of their own they found none of your games. Any other program can
    be put there by hand: right-click its card and choose "Run with Steam".
  - Before such a program starts, Magic Kettle starts Steam in the background, the way it always starts it. A
    Steam started by r2modman itself checked its files, undid what Magic Kettle does to show its window, and hung
    without one, so the game never started.
  - Programs can ask Windows PowerShell for registry values again. Wine's PowerShell does nothing, and r2modman,
    which finds Steam that way, said "Unable to resolve steam install folder". Magic Kettle now puts a small
    PowerShell of its own into each game's Windows that answers these questions (`Get-ItemProperty`); anything
    else it reports as not possible here, as before.
  - A game that Steam starts with extra arguments is left as it is. Magic Kettle used to close a game started
    from Steam and start it again its own way when its settings weren't known yet; that dropped r2modman's
    arguments, and Muck came back without its mods.
- **Single-file Electron programs open as programs, not installers.** r2modman's one-file download (and other
  "portable" builds made with electron-builder) is packed like an NSIS installer, so Magic Kettle asked where to
  install it and then ran it as an installer. It only unpacks the program to a temporary folder and starts it;
  Magic Kettle now tells it from a real installer and adds it to the library like any other program. It also
  knows such a program is Electron from the start, so the first launch no longer waits a minute and a half on an
  empty window before trying another way, and it draws without the GPU: with it, r2modman's title bar was a
  see-through strip over whatever was behind the window. Since it draws without the GPU, there is no graphics to
  look for either: it starts at once, without the first-launch screen, and with Steam in the graphics Steam
  already runs in, rather than restarting Steam for each one tried. Its window is looked for in the process it
  unpacks, so it is no longer taken for a program that never opened one.

- **Deleting from disk a game that sits in Downloads takes only its program, not your Downloads.** A game or
  program opened straight from Downloads, the Desktop or the top of a disk had that whole folder as its "game
  folder", and "Delete… › From disk" would have moved all of it to the Trash. Now only the exe goes there, and the
  delete window says so and shows its size, not the size of Downloads.
- **Opening the same exe from Downloads again finds its card.** Magic Kettle doesn't write its small marker file
  into shared folders, so each double-click on a program there added a new card, which looked for its launch
  settings all over again. It is now found by its path. A duplicate card made by an earlier version can be removed
  with "Delete… › Only from Magic Kettle".

## What to watch for

- A game that ships its own `winhttp.dll`, `version.dll` or `dinput8.dll` for another reason now loads that copy
  too. If a game that worked in 1.0.8 stops starting, that is the first thing to report.
- A program that asks PowerShell for anything other than a registry value still gets nothing, now with a short
  error instead of silence. If a launcher or mod manager reports that PowerShell failed, that is worth a report.
