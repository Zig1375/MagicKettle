Magic Kettle 1.0.10: Automatic OpenGL fallback for Godot 4 games.

## New in this version

- **Godot 4 games automatically retry with OpenGL when Direct3D 12 fails at startup.** Magic Kettle recognizes
  device and compute pipeline errors in the game log, closes the failed attempt and tries the Compatibility
  renderer. When it works, Magic Kettle remembers the renderer for the next launch. This also fixes an error
  dialog being mistaken for a running game.
  - Verified with Nightmare Erosion. The game opened after the automatic retry and Magic Kettle saved the
    working renderer. Some effects that require Godot's Forward+ renderer may look different in Compatibility mode.
